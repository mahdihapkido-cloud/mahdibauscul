# سیستم توزین خودرو 🚗⚖️

یک سیستم خودکار برای توزین خودروها و ثبت محصولات با استفاده از **OCR** و **PyQt6**

---

## ✨ ویژگی‌ها

✅ خواندن خودکار **پلاک ماشین** (OCR)  
✅ خواندن خودکار **وزن نمایشگر دیجیتالی** (OCR)  
✅ مدیریت **دو مرحله‌ای**: خالی و بار شده  
✅ محاسبه خودکار **وزن خالص**  
✅ تولید **فیش PDF** و چاپ  
✅ صادرات **گزارش Excel**  
✅ رابط **فارسی‌زبان** و کاربرپسند  
✅ **پایگاه داده SQLite** برای ذخیره‌سازی

## 📖 نحوه استفاده

> پلاک و وزن **فقط خودکار** از دوربین خوانده می‌شوند و کاربر نمی‌تواند آن‌ها را دستی تغییر دهد.
> تنها ورودی کاربر، **انتخاب کد محصول** است.

صفحه‌ی اول سه گزینه دارد:

### ۱️⃣ ثبت وزن ماشین (الزامی)

1. ماشین **خالی** را روی باسکول قرار دهید
2. **«خواندن پلاک و وزن»** را بزنید (پلاک و وزن خودکار خوانده می‌شود)
3. **«ثبت وزن ماشین»** را بزنید

### ۲️⃣ اضافه کردن بار به ماشین خالی

1. بعد از بارگیری، **«خواندن پلاک و وزن»** را بزنید
2. **کد محصول** را انتخاب کنید
3. سیستم **خالص بار** را نشان می‌دهد: `وزن فعلی − وزن قبلی ماشین = خالص بار`
   (وزن قبلی = وزن خالی ماشین، یا وزن بعد از بار قبلی)
4. **«ثبت این بار»** را بزنید؛ برای محصول بعدی دوباره تکرار کنید

### ۳️⃣ اتمام بار و دریافت فیش

1. **«خواندن پلاک»** را بزنید تا بارهای ثبت‌شده‌ی ماشین نمایش داده شود
2. **«صدور و چاپ فیش»** را بزنید

> ناحیه‌ی اعداد نمایشگر باسکول (کادر سبز) و انتخاب دوربین‌ها از «تنظیمات دوربین» در صفحه‌ی اول انجام می‌شود.

## ⚙️ مدیریت محصولات

### اضافه کردن محصول جدید:

1. **"تنظیمات محصولات"** را بزنید
2. **کد محصول** و **نام** را وارد کنید
3. **"اضافه"** را بزنید

مثال:

## 🔧 تنظیمات

### تغییر دوربین:

در `ui.py` سطر بالا:
```python
self.camera_thread = CameraThread(0)  # 0 = دوربین اول
# تغییر به 1 برای دوربین دوم
```

### تغییر محصولات پیش‌فرض:

در `ui.py` متد `load_products()`:
```python
default_products = [
    ('BRR001', 'برنج'),
    ('PRN001', 'پرنج'),
    ('GLR001', 'گلاب'),
    ('OIL001', 'روغن'),
]
```

## 🐛 حل مشکلات

### دوربین باز نمی‌شود:
```python
# چک کن شماره دوربین صحیح است
cap = cv2.VideoCapture(0)  # یا 1
```

### OCR درست کار نمی‌کند:
1. نور اتاق را بهتر کن
2. دوربین را تمیز کن
3. نمایشگر را مستقیم روبه‌روی دوربین قرار بده

### پرینتر کار نمی‌کند:
- مطمئن شو پرینتر پیش‌فرض تنظیم شده است
- درایور پرینتر را به‌روزرسانی کن

## 📝 فایل‌های پایگاه داده

### جدول `weighing`:
- `id` - شماره ردیف
- `plate_number` - پلاک
- `empty_weight` - وزن خالی
- `final_weight` - وزن نهایی
- `net_weight` - وزن خالص
- `product_code` - کد محصول
- `receipt_number` - شماره قبض
- `status` - وضعیت (waiting/completed)

### جدول `products`:
- `code` - کد
- `name` - نام محصول
